# A single Appreciation may carry 1–N Red Flowers

A Giver may attach between 1 and their remaining-quota Red Flowers to a single Appreciation, rather than the count being fixed at 1.

We chose variable value over a fixed 1-flower-per-appreciation model so that a Giver can express strength of recognition. The trade-off is extra complexity in the UI, the ranking math, and the audit trail — and the risk that high-value flowers concentrate on already-popular Receivers, which we accept given the daily-quota + public-record constraints.
