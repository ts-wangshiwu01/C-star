# Quota is measured in Red Flowers, not in Appreciation acts

The Period Quota counts Red Flowers awarded, not Appreciations sent. Each Appreciation consumes 1–N Red Flowers from the Giver's remaining quota.

We chose this over counting acts because the alternative — counting Appreciations regardless of how many flowers each carries — lets a Giver dump an unbounded number of flowers in a single act, making the quota meaningless given that flowers carry 1–N value (see ADR-0002) and feed the all-time ranking.
